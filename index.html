🎰 小瑪莉（麻仔台）操作與按鍵說明

🎯 遊戲基本玩法

  1. 投幣與押分：點擊「投幣」或「開分」增加可用分數（CREDIT），接著點擊下方 8 種水果/圖案進行押分。
  2. 啟動跑燈：按下 START 啟動外圍 24 格跑馬燈，停在有押注的圖案即按賠率獲得 WIN 分數（停在歸零或幸運草有送燈特效！）。
  3. 比大小（比倍）：中獎後可點擊「DOUBLE 比大小鍵」或直接選「押小 (1~6)」、「押大 (8~13)」。開出 7 為保送（翻倍過關）！

🕹️ 主要按鍵與限制說明

  • START（開始鍵）：押注後啟動跑燈；若未改押分直接按壓，會自動延續上一局押注值直接開始。若有贏分未收，按 START 會自動先收分。
  • DOUBLE UP / BET（比大小）：中獎後進入 1~13 點數比倍模式。
  • WIN / CREDIT（左/右移分鍵）：將贏分收進可用區（◀得分），或在無押分狀態下將分數移至贏分區（移分▶）。
  • PAY（退幣鍵）：在無押分狀態下，將剩餘分數轉換為硬幣退出（機台內剩餘硬幣需大於等於退幣量才可正常退幣）。
  • 開分鍵 / 消分鍵：每按一次 +100 分 / -100 分（嚴格限制需在無押分狀態下操作）。
  • 電源開關：控制主機台開啟與關閉，當機或想重置機台時可關機再重開。

💧 水箱機制與咬度演算法說明

  • 水箱水位：玩家每局押分的 95% 會注入機台水箱。水箱充足時，大獎（BAR、77、星星）與幸運送燈（ONCE MORE）開出率大幅提高！
  • 吐分期 (RTP 98%)：水箱放水，送燈機率提高至 15~20%，且送 3~4 燈機率極大。
  • 標準街機 (RTP 92%)：原汁原味街機咬度，水箱充飽即吐獎。
  • 吃分期 (RTP 80%)：機台保護水箱，優先開出小獎或玩家未押注之圖案。
